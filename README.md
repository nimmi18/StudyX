# Offline AI Tutor



An AI-powered learning assistant designed to help students study with locally running AI models.



## Features



- Ask AI Tutor: Ask questions and receive AI-generated explanations.

- Generate Quiz: Generate multiple-choice questions for practice.

- Ask from PDF: Upload study material in PDF format and ask questions about its content.



## Technology Stack



- Python

- Streamlit

- Ollama

- Llama 3.2

- PyMuPDF
